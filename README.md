# Festa Fantasia - ETEC / Centro Paula Souza

Aplicativo web mobile-first para o mural de fotos e votação de fantasias dos alunos da ETEC.

## Recursos

- **Mobile First**: Desenvolvido para visualização rápida no celular.
- **Identidade Visual**: Cores preto, branco e vermelho oficial do Centro Paula Souza (`#b21f24`).
- **Foto Direta**: Tire foto com a câmera do smartphone ou selecione da galeria.
- **Editor de Imagem**: Enquadramento 4:5, zoom e posicionamento por toque na tela.
- **Curtidas**: Sistema de votos em JavaScript com persistência em `localStorage`.
- **Moderação / Administração**: Painel protegido por senha para excluir fotos se necessário.

## Cursos da ETEC

- Administração
- Desenvolvimento de Sistemas
- Farmácia

## Painel de Moderação

- **Senha Padrão**: `admin`
- **Acesso**: Ícone de cadeado no topo, botão de moderação no rodapé ou atalho `Ctrl + Shift + A` (ou parâmetro `?admin=1` na URL).
